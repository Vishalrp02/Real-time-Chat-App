# Real-Time Chat Rooms 💬

A real-time group chat application where users can create or join chat rooms and exchange messages instantly.  
Built using **Node.js**, **Express**, **Socket.IO**, **Mustache**, **Moment.js**, and a bad-words filter for a safe and fun chatting experience.

## ✨ Features
- 🏠 **Room-based chat** – Create or join custom chat rooms
- ⚡ **Instant messaging** – Real-time communication powered by Socket.IO
- ⏰ **Timestamps** – Messages display formatted time using Moment.js
- 😇 **Profanity filter** – Bad words are automatically blocked
- 🎨 **Dynamic templates** – Mustache templates for rendering chat UI
- 📱 **Responsive** – Works across desktop and mobile browsers

## 🛠 Tech Stack
- **Backend:** Node.js, Express.js
- **Real-time Engine:** Socket.IO
- **Templating:** Mustache
- **Utilities:** Moment.js, Bad-words (profanity filter)
- **Frontend:** HTML, CSS, JavaScript
